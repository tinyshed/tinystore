## restore

```rust
pub fn restore(archive: impl AsRef<Path>, dir: impl AsRef<Path>) -> Result<Backup>
```

Restores the backup at `archive` into `dir`, which is empty or absent,
before a store opens there; the store's `LOCK` is held meanwhile, so that
none opens before the restore ends. A file that does not match what the
backup says of it fails the restore `Corrupt`, and leaves `dir` empty.

### BackupBuilder.include


Includes a file of the program's, by its path inside the store's
directory, such as `secret.key`, which a restore puts back where it
was. A backup holds no file but the engines' unless one is named.

### BackupBuilder.include_encryption_key

```rust
pub fn include_encryption_key(self) -> Self
```

Includes the store's encryption key, as it is, which a backup leaves
out otherwise: the zip is not encrypted, so a backup with the key
opens every value it holds, and is kept as safely as the key. While
values are sealed, a key that is not where the store reads it fails
the backup, as beside a server that keeps its key apart.

### BackupBuilder.write

```rust
pub fn write(self, path: impl AsRef<Path>) -> Result<Backup>
```

Writes the backup to `path` whole: beside it first, then renamed once
synced, so that a backup that fails leaves no zip.

### BackupBuilder.write_to

elsewhere: what `out` holds of a backup that fails is no backup.
