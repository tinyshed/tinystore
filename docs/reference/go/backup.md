## Store.Backup

```go
func (s *Store) Backup(ctx context.Context, path string, opts ...BackupOption) (Backup, error)
```

Backup writes a backup of every engine of the store to path as one zip, made while the store keeps working, which tinystore restore takes back into an empty directory. It is written beside path and renamed once whole, so that a backup that fails leaves no zip; a connection lost on the way makes it again from its start.

	backup, err := store.Backup(ctx, "backup-2026-10-13.zip")
