### Wait


Wait is how long a hold waits in line for its key, 10 s unless given: a key still held past it is ErrInUse.

### OpenLock


OpenLock opens a lock: keys held one holder at a time, across every program of the store.

### Lock.Hold

```go
func (l *Lock) Hold(ctx context.Context, key any, fn func(ctx context.Context, lease *Lease) error, opts ...HoldOption) error
```

Hold waits for key in line, holds it while fn runs and lets it go. A key still held past the wait is ErrInUse; a lease lost while fn ran ends its ctx, and Hold is ErrLost though fn succeeded, since another holder may have run beside it.

### Lock.TryHold


TryHold holds key while fn runs if nobody holds it, and says whether it did.

## Option

```go
type Option func(*keys)
```

Option is how a lock or a semaphore opens.

### Limit

```go
func Limit(n int) Option
```

Limit is how many may hold a semaphore's key at once, 1 to 1000.

### MaxHold

```go
func MaxHold(d time.Duration) Option
```

MaxHold is how long a lease lasts from its grant, however it is renewed: past it the next in line holds the key, and the holder's ctx ends.

### TTL

```go
func TTL(d time.Duration) Option
```

TTL is how long a lease lasts from its last renewal, 1 s to 1 hour, 10 s unless given; this program renews it at a third of it while the function runs.
