# Releases

What changed in each version of TinyStore, with code in every language. One
version covers the Rust crates, the Bun and Node, Python and Go SDKs, the
command line and the server image.

- **[TinyStore 0.6.0](v0.6.0.md)** · 3 November 2026\
  An audit that commits with the database change, what a stream's events
  carry, a gauge corrected after the fact, config entries, a plugin's settings
  chosen by its name, settings without SQLite, a Rust program's own MCP
  server and one rule for colours.
- **[TinyStore 0.5.1](v0.5.1.md)** · 2 November 2026\
  Search keeps its postings in segments: an import of millions of documents
  in minutes, faster searches, and a dropped index's pages back to the disk.
- **[TinyStore 0.5.0](v0.5.0.md)** · 1 November 2026\
  Every word as a prefix, the other keyboard layout, where each hit matched,
  a bucket's `update`, limits by name and `status --names`.
- **[TinyStore 0.4.1](v0.4.1.md)** · 31 October 2026\
  Search as you type with `prefix`, and one value for a key that a nested
  `with` gives again.
- **[TinyStore 0.4.0](v0.4.0.md)** · 27 October 2026\
  Files that commit with a database's rows, older encryption keys, a backup
  of one moment, and a metrics.db less than half as large for per-second
  series.
- **[TinyStore 0.3.0](v0.3.0.md)** · 27 October 2026\
  Metrics read and aggregated in pages, a command line that writes to a
  store, a command run under a lock, an AI agent that may write.
- **[TinyStore 0.2.0](v0.2.0.md)** · 26 October 2026\
  Event ids, metrics that are safe to retry, a whole scrape in one write,
  calendar aggregates, a rate for each group of jobs.
- **[TinyStore 0.1.1](v0.1.1.md)** · 24 October 2026\
  Async Rust, Prometheus exporters, a job in a database's batch, log levels
  for the store and the console.
- **[TinyStore 0.1.0](v0.1.0.md)** · 20 October 2026\
  The first release.

Until 1.0, a minor release may rename what a program calls, and its page
lists every such change first. A store that one release wrote always opens
in the next.
